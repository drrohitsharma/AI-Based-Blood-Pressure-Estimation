# AI-Based Blood Pressure Estimation

**Machine Learning for Non-Invasive Blood Pressure Estimation**

## 1. Overview

This project explores machine learning approaches for non-invasive blood pressure estimation using physiological signals.

The primary objective is to investigate signal processing, feature extraction, and machine learning techniques for estimating:

- Systolic Blood Pressure (SBP)
- Diastolic Blood Pressure (DBP)

## 2. Research Objectives

- Explore physiological signals for blood pressure estimation.
- Develop signal preprocessing pipelines.
- Extract meaningful physiological features.
- Implement and compare machine learning models.
- Evaluate model performance using appropriate statistical metrics.
- Develop reproducible research workflows.

## 3. Proposed Methodology

1. Public dataset identification and assessment.
2. Data exploration and quality assessment.
3. Signal preprocessing.
4. Feature extraction.
5. Machine learning model development.
6. Model evaluation and comparison.
